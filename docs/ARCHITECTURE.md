# Архитектура: две плоскости

## L — локальный рантайм (продукт)

Четвёрка доменных агентов на локальной модели, оркестрованная Python-кодом.
Видит настоящие документы. Никогда не выходит в облако.

```
Telegram-канал ──┐
                 ├──► segregator-bot (whitelist, очередь, режимы IDLE/ACTIVE/BATCH)
экспорт 2025 ────┘             │
KSeF 2.0 (FA(3)) ──────────────┤
                               ▼
        Agent-01 OCR/KSeF  ──► DocumentFacts   (что написано в бумаге)
                               ▼
        Agent-02 Księgowy  ──► BookingProposal (как это провести)
                               ▼
        дерево + SQLite + XLSX-реестр
                               ▲
        Agent-03 Kadrowy   ──► PayrollFacts    (PIT-11, ZUS, периоды года)
        Agent-04 Doradca   ──► AdvisoryReport  (сценарии, допущения, неизвестные)
```

Контракты между агентами — JSON-схемы в `agents/schemas/`. Агент не знает, кто
его вызвал и кто получит результат: он получает объект и возвращает объект.
Это то, что позже позволит вынести любого из них в отдельный процесс.

Деньги считает Python, модель объясняет. Калькуляторы покрыты тестами и
версионированы по годам (`rates/<year>.toml`); симулятор отказывается считать
год, для которого таблицы нет.

## C — Claude Code (разработка)

Субагенты в `.claude/agents/`, работают с кодом, правилами и синтетическими
фикстурами. Настоящие документы им запрещены `.claude/settings.json`.

| Субагент | Зачем |
|---|---|
| `boundary-guard` | Ищет, чем именно новый код может пробить контур данных |
| `rules-smith` | Правила классификации вместе с тестами; снимает нагрузку с модели |
| `pl-tax-checker` | Сверяет ставки, базы и регуляторные даты с первоисточниками |
| `agent-prompt-smith` | Промпты, JSON-схемы и golden-тесты четвёрки |

## Что поменял KSeF

Проверено 2026-08-31: обязательный KSeF уже действует — с 1 февраля 2026 для
крупных, с 1 апреля 2026 для остальных, включая JDG. Приём фактур через KSeF
обязателен для всех с 1 февраля 2026. Структура — FA(3), API — KSeF 2.0.
Переходный лимит 10 000 zł/мес на фактуры вне системы — до 31 декабря 2026,
с 1 января 2027 полный санкционный режим.

Следствие: для документов с апреля 2026 KSeF — основной канал, приходит валидный
XML, OCR не нужен. OCR остаётся для чеков, зарубежных фактур и для архива 2025,
который в KSeF никогда не попадал. То есть Agent-01 — это два разных пути с
общим выходом, и путь через KSeF со временем становится главным.
