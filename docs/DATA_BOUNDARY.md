# Контур данных — что и куда имеет право уходить

## Инварианты

1. Ни один байт содержимого документа не уходит в облако. Ни в переписку,
   ни в облачную модель, ни в телеметрию.
2. Единственный разрешённый внешний сетевой партнёр рантайма — **KSeF API**
   (сервера Министерства финансов РП), и только по явно включённому флагу.
   Telegram Bot API — второй, и он видит только то, что ты сам просишь прислать.
3. PESEL, IBAN и номера карт маскируются везде, кроме самого генерируемого
   официального документа. В логи, в карточки бота и в промпты модели они не попадают.
4. Логи содержат идентификаторы, категории и уверенность — не текст документов.
5. Audit trail (ślad rewizyjny) — append-only: кто, когда, на основании какого
   правила изменил проводку. Требование Ustawa o rachunkowości.
6. Хранение — 5 лет от конца календарного года, в котором наступил срок уплаты
   налога (практически почти 6 лет). Удаление раньше срока запрещено кодом.

## Как проверяется, а не обещается

- `.claude/settings.json` запрещает Claude Code читать экспорт, архив, блобы, БД и логи.
- Сессии ассистента выдана только папка с кодом; папка экспорта не подключена.
- Тест `tests/test_data_boundary.py` падает, если:
  - в коде появился HTTP-клиент на пути обработки документа с хостом вне allowlist;
  - логгер вызывается с полем, помеченным как `sensitive`;
  - в `tests/fixtures/` попал файл, не помеченный как синтетический.
- Скрипты из `probe/` печатают только счётчики и размеры.

## Что это ломает и как мы с этим живём

Ассистент не видит проблемный документ. Отладка идёт по обезличенному описанию:
тип, длина текста, какие поля нашлись, какие regex сработали, номер ступени
каскада. Для воспроизведения проблемы делается синтетическая фикстура с той же
структурой и другими данными.
