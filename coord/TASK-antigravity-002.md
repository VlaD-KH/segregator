### Контракт

```python
def safe_filename(name: str, *, max_stem: int = 120) -> str
```

Правила применяются **в этом порядке** — он проверяется тестами:

1. Каждый запрещённый на NTFS символ `< > : " / \ | ? *` и каждый управляющий
   символ (`ord(c) < 32`) заменяется на `_`. Один символ — один `_`.
2. С конца строки снимаются точки и пробелы, пока они там есть. Windows
   отбрасывает их молча, и файл оказывается не под тем именем, что записано в БД.
3. Если часть имени **до первой точки** совпадает (без учёта регистра) с именем
   устройства — впереди добавляется `_`. Список закрытый:
   `CON PRN AUX NUL COM1…COM9 LPT1…LPT9`. Совпадение только целиком:
   `CONTRAKT.pdf` — обычное имя и остаётся собой.
4. Основа (`Path(name).stem`) режется до `max_stem` символов, расширение
   (`Path(name).suffix`) сохраняется целиком. Предел пути NTFS — 260 (F-5.5).
5. Если после всего строка пуста — возвращается `"bez-nazwy"`.

**Польская диакритика не трогается.** `ąćęłńóśźż ĄĆĘŁŃÓŚŹŻ` — законные символы
NTFS, архив польский, транслитерация здесь была бы порчей данных.

```python
def unique_path(target: Path, *, limit: int = 999) -> Path
```

Свободный путь возвращается как есть. Занятый получает суффикс `__2`, `__3`, …
**перед расширением**: `faktura.pdf` → `faktura__2.pdf`, а не `faktura.pdf__2` —
иначе файл перестаёт открываться. Имя без расширения работает так же:
`faktura` → `faktura__2`.

Исчерпав `limit`, функция поднимает `FileExistsError`. Возвращать занятый путь
нельзя: вызывающий запишет поверх чужого документа.

## Зачем это нужно

`_route_to_archive` (`service.py:390`) чистит из имени файла только `/`:

```python
doc_nr_clean = (facts.doc_number or "fv").replace("/", "_")
```

Номер фактуры приходит **из документа**, то есть от постороннего. Отсюда три
разных отказа, и все тихие:

1. `FV\12\2026` — обратный слэш не чистится, файл уезжает в несуществующий
   подкаталог или падает на середине раскладки;
2. `FV:12/2026` — двоеточие на NTFS не создаётся вовсе, документ теряется, а
   проводка в книге остаётся: реестр ссылается на бумагу, которой нет;
3. два документа с одинаковым именем — `shutil.copy2` затирает первый молча.

Твой модуль закрывает F-5.5 и даёт третьему пункту опору: `unique_path`.
