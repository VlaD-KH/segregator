# Segregator

Разбор Telegram-канала «бухгалтерия» в архив: дерево папок по месяцам и
категориям, SQLite с полнотекстовым поиском, XLSX-реестр для бухгалтера.

ТЗ: см. артефакт «ТЗ Segregator».

## Контур данных (жёсткое правило проекта)

Документы и всё, что из них извлечено, **не покидают эту машину**.

| Где | Что там происходит |
|-----|--------------------|
| Локально (эта машина) | Парсинг экспорта, OCR, локальная LLM, извлечение полей, классификация, дерево, БД, реестр |
| Облако (ассистент) | Только код, конфиги, схемы, правила, агрегированные счётчики и тексты ошибок |

Правила, которые соблюдаются без исключений:

- Папка экспорта **не подключена** к облачной сессии и не будет подключена.
- Ни один документ, ни один фрагмент его текста, ни одно извлечённое поле и
  ни одно имя файла из архива не отправляются наружу.
- Скрипты профилирования печатают только счётчики, размеры и распределения.
  Всё, что содержит имена и содержимое, пишется в локальный файл и остаётся тут.
- Внешние LLM-API в проекте не используются: классификация идёт на локальной модели.
- Токен бота живёт в `.env` рядом с кодом (права только владельцу) и никогда
  не попадает ни в репозиторий, ни в логи, ни в переписку.

## Как запустить разведку

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\Huawei\source\segregator\probe\01_host_and_export.ps1"
```

Скрипт пишет `probe/probe_result.txt`. Открой его и убедись сам, что там нет
ничего, кроме цифр, — и только после этого дай знать, что можно читать.
