# Segregator — рабочая память ai-loop

Читается в начале каждой фазы. Лимит — две страницы.
Полное ТЗ живёт отдельным артефактом claude.ai («ТЗ Segregator»), не в репозитории.

## Что это за проект

Автономная бухгалтерская ИИ-система для Польши (JDG и Sp. z o.o.). Первый
работающий кусок — разбор Telegram-канала «бухгалтерия» в архив: дерево папок
по месяцам и категориям, SQLite с полнотекстовым поиском, XLSX-реестр для
бухгалтера. Пользователь один — владелец JDG, он же единственный, кому бот
отвечает.

## Правило номер один

Документы и всё, что из них извлечено, **не покидают эту машину**. Плоскость L
(локальный рантайм) видит настоящие фактуры, PESEL, суммы; плоскость C
(Claude Code) — только код, правила, схемы и синтетические фикстуры.

Владелец предлагал дать доступ к `JDG/` со своими оригиналами. **Отказано и
закрыто механизмом:** контекст ассистента уходит в облако, разрешение владельца
не убирает канал. С коммита `a2b6e08` в `deny` стоят `Read(./JDG/**)`,
`Read(./ChatExport_*/**)`, `Read(./**/.env)`. Для отладки — синтетика из
`tests/fixtures/` или обезличенный выхлоп `probe/`.

## Железо (замерено)

Ryzen 5 3500U, Vega iGPU, **NVIDIA нет** → vLLM не используем. RAM 6.9 ГБ.

## Острые края — то, что стоило крови

- **`classify_diff.py` только вычисляет, в ledger пишет `loop.py gate`.**
  Классификация без gate оставляет коммиты вне записи; чинится записью задним
  числом, но причинная цепочка тогда восстановлена постфактум.
- **Глобальный editable-install указывает на `…\segregator\src`** (дерево `main`).
  Любой `python -c "import segregator"` из другого worktree импортирует код
  `main`, а не ветки. Под pytest замаскировано `pythonpath = ["src"]` в
  `pyproject.toml`; вне pytest нужен явный `PYTHONPATH`.
- **Консоль здесь cp1250.** Python, печатающий кириллицу или польские буквы,
  падает с `UnicodeEncodeError` без `PYTHONIOENCODING=utf-8`.
- **144 зелёных теста, чистый `boundary-guard` и закрытый `pl-tax-checker` не
  увидели ни одного из восьми блокеров.** Зелёный прогон здесь не доказательство.
- **`total_spoleczne` не включает `fundusz_pracy`.** В декларации DRA это разные
  блоки (IV/p7 и VIII/p1 против IX/p1 и IX/p3); свернув их, KEDU-XML считает FP дважды.
- **`kpir_entries` не содержит `taxpayer_nip`** — система однопользовательская,
  агрегат считается по периоду целиком.
- **Remote Control показывает только рабочий каталог сессии.** Соседние worktree
  из него не видны, файл «пропал» именно поэтому.
- SessionStart-хук здесь **срабатывает** — проверено.

## Решения, которые уже приняты

- Дерево строится **hardlink**, не копиями. Код пока делает `shutil.copy2` —
  это блокер 8, чинится приведением кода к решению, а не отменой решения.
- Эскалированный документ: **отдельная таблица `kpir_quarantine`** плюс раскладка
  в архив. Не флаг в `kpir_entries` — тогда каждый новый читатель обязан помнить
  про фильтр.
- Дисклеймер советника — сверка с канонической константой `DISCLAIMER_PL`
  целиком. Поиск подстроки ошибался в обе стороны: отвергал правильные польские
  формулировки и пропускал прямо противоположную.
- `Edit(./src/**)` остался в `allow`, чувствительные файлы вынесены в `ask`.
  Приоритет `deny > ask > allow`, поэтому точечные `ask` выигрывают.
- `LLM_BACKEND=llama.cpp`, не Ollama. Внешних LLM-API нет; валидатор конфига
  падает на не-loopback адресе.
