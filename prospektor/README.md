# prospektor

Поиск бизнесов и скоринг их цифровых разрывов: нет сайта, нет приёма заказов онлайн,
слабое SEO, невидимость для ИИ-ассистентов. На выходе не карта, а список лидов, где под
каждым видно, **что именно сломано, чем это подтверждается и что предложить**.

Модуль изолирован от основного проекта (`segregator`): свой `pyproject.toml`, своя база,
свои права в `.claude/`, ноль импортов через границу в обе стороны. Граница проверяется
тестом, а не договорённостью — см. `tests/test_isolation.py`.

Подробная инструкция по запуску — [`docs/RUNBOOK.md`](docs/RUNBOOK.md).
Результаты прогонов на живых городах — [`docs/RUN-SZCZECIN.md`](docs/RUN-SZCZECIN.md)
и [`docs/RUN-STARGARD.md`](docs/RUN-STARGARD.md).

## Быстрый старт

```bash
cd prospektor
python3.12 -m venv .venv
.venv/bin/pip install -e '.[dev,xlsx,web]'
.venv/bin/pytest                      # 143 теста, полностью офлайн

.venv/bin/prospektor discover --area Szczecin --profile beauty_pl
.venv/bin/prospektor enrich
.venv/bin/prospektor audit --profile beauty_pl --limit 200
.venv/bin/prospektor score --profile beauty_pl
.venv/bin/prospektor query beauty-tylko-platforma --profile beauty_pl --export xlsx
.venv/bin/prospektor serve             # дашборд на http://127.0.0.1:8080
```

## Конвейер

| Стадия | Что делает | Куда ходит |
|---|---|---|
| `discover` | ищет кандидатов по территории и категориям | карты и реестры |
| `enrich` | пересобирает карточку из фактов, разрешая конфликты источников | никуда |
| `audit` | грузит сайты отобранных кандидатов и прогоняет пробы | сайты самих бизнесов |
| `score` | считает `gap` / `fit` / `priority` по профилю | никуда |
| `query` | фильтрует и выгружает CSV/XLSX | никуда |
| `dossier` | собирает markdown-досье на один лид | никуда |
| `serve` | локальный дашборд, только чтение | никуда |
| `doctor` | показывает склейки, которые стоит проверить глазами | никуда |

Каждая стадия пишется под своим `run_id`, идемпотентна и кэширует загрузки по TTL:
прерванный прогон продолжается, а не начинается заново.

## Что измеряется

Пять групп сигналов. Полный каталог с формулировками для разговора с владельцем —
в [`docs/SIGNALS.md`](docs/SIGNALS.md).

- `web.*` — есть ли работающий сайт, или это заглушка, профиль на чужой площадке, страница в соцсети, вёрстка 2019 года. Отдельно различаются «сайта нет» и «проверить не удалось»
- `seo.*` — title, description, индексируемость, согласованность NAP между сайтом, картой и реестром
- `aio.*` — читаемость для ИИ-агентов: JSON-LD, машиночитаемое меню, теги диет,
  допуск GPTBot/ClaudeBot/PerplexityBot, зависимость контента от JS
- `ops.*` — приём заказов: свой канал, только агрегатор, только телефон; запись, чат, форма
- `rep.*` — рейтинг и отзывы как прокси спроса

## Две оценки, а не одна

`gap` — сколько сломано. `fit` — есть ли спрос и кому платить. Смешивать нельзя:
заведение с рейтингом 4.6 и 400 отзывами без сайта и заведение с 2.1 и пятью отзывами
имеют **одинаковый** `gap` и совершенно разную ценность как лид.
`priority` — геометрическое среднее, поэтому нулевой `fit` обнуляет приоритет.

Рядом идёт `coverage` — доля правил профиля, которую удалось измерить: разрыв 100
по двум правилам из девятнадцати и по пятнадцати — разные утверждения.

Веса живут в `profiles/*.yaml` и калибруются на первых лидах. Ни одна цифра не приходит
от модели: балл — сумма весов правил, правило ссылается на сигнал, сигнал на evidence
(URL, время, хэш куска HTML).

## Фильтры — это файлы

«Разовый тематический» срез добавляется файлом в `queries/`, а не правкой кода:

```yaml
where:
  - city: [Kielce, Radom]
  - cuisine_in: [asian, japanese]
  - rep.reviews_count: {gte: 80}
  - any_of:
      - web.has_site: false
      - aio.menu_is_image_only: true
      - ops.aggregator_only: true
order_by: priority desc
```

## Источники и законность

По умолчанию включены только источники, чья лицензия или официальный API прямо
разрешают использование: Overture Places (CDLA), OSM/Overpass (ODbL), CEIDG/KRS/REGON,
Google Places API (платный, с бюджетным потолком), сайты самих бизнесов с соблюдением
robots.txt. Overture читается либо DuckDB, либо HTTP range-запросами через pyarrow —
что установлено, тем и читается; около 30 МБ на город в обоих случаях. Подробности, лимиты и цены — в [`docs/SOURCES.md`](docs/SOURCES.md).

«Серые» источники (разбор публичных страниц Google Maps, сторонние SERP API) описаны
интерфейсом, но выключены и требуют двойного включения: `PROSPEKTOR_ALLOW_GRAY=1`
плюс `--legal-mode gray`. Факт использования пишется в манифест прогона.

## RODO

Для JDG контактные данные — персональные данные владельца, а польская практика UODO
по B2B-обращениям строже, чем в большинстве ЕС. Поэтому: пометка `personal_data` на
уровне полей, режим выгрузки `--no-pii`, таблица сроков хранения и команда `purge`,
шаблон LIA в [`docs/legal/LIA.md`](docs/legal/LIA.md).

**Модуль готовит список — связывается с бизнесом человек.** Это та же граница, что в
основном проекте: агент готовит файл, отправляет человек.

## Настройки

Через переменные окружения с префиксом `PROSPEKTOR_` или файл `.env`:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PROSPEKTOR_USER_AGENT` | безымянный | **Замените**: указывайте контакт, это вежливость и защита от банов |
| `PROSPEKTOR_BUDGET_USD` | `0.0` | Потолок трат на платные API за прогон. Ноль = платные источники запрещены |
| `PROSPEKTOR_CONCURRENCY` | `8` | Параллельных загрузок в стадии audit |
| `PROSPEKTOR_PER_HOST_DELAY` | `1.0` | Пауза между запросами к одному хосту, секунды |
| `PROSPEKTOR_CACHE_TTL_HOURS` | `168` | Сколько живёт кэш загрузок |
| `PROSPEKTOR_GOOGLE_API_KEY` | — | Ключ Places API; без него адаптер не активируется |
| `PROSPEKTOR_PAGESPEED_API_KEY` | — | Ключ PageSpeed Insights для метрик `seo.psi_*` |
| `PROSPEKTOR_ALLOW_GRAY` | `0` | Первый из двух замков «серых» источников |

Пути принудительно удерживаются внутри `prospektor/`: попытка направить базу или выгрузку
наружу отклоняется настройками, а не полагается на внимательность.

## Вынос в отдельный репозиторий

```bash
git subtree split --prefix=prospektor -b prospektor-standalone
```

Ничего переписывать не нужно: модуль ни на что снаружи не ссылается.
