# Источники данных

Каждый адаптер объявляет три вещи, и все три попадают в манифест прогона: правовой
режим, лимит скорости и стоимость вызова. Без этого нельзя ни отвечать за законность
выборки, ни удержать бюджет.

Проверено 2026-09-07. Цены и лимиты меняются — при расхождении верить поставщику,
а не этой таблице.

## Tier 1 — чистые, включены по умолчанию

### Overture Maps Places — массовый костяк

Порядка 72 млн POI мира лежат parquet-ом на S3 и читаются DuckDB прямо оттуда: с
bbox-фильтром скачивается только нужный кусок. Ключей и регистрации не требуется.

- Лицензия: **CDLA Permissive 2.0 / Apache 2.0** — коммерческое использование разрешено
- Стоимость: 0 (только трафик)
- Слабое место: контакты беднее, чем в OSM; релиз пересобирается раз в месяц
- Релиз фиксируется явно (`PROSPEKTOR_OVERTURE_RELEASE`): «последний» ломает
  воспроизводимость выборки
- Ставится отдельно: `pip install -e '.[overture]'`

### OpenStreetMap / Overpass — свежесть по мелкому бизнесу

У POI в OSM есть готовые теги `website`, `phone`, `opening_hours`, `cuisine`,
`delivery`, `takeaway` — половина нужных фактов приходит сразу, без обхода сайта.

- Лицензия: **ODbL** — коммерческое использование при указании авторства
- Стоимость: 0
- Публичный инстанс волонтёрский: для регулярных прогонов поднимается свой
  (`PROSPEKTOR_OVERPASS_URL`), пока — вежливый таймаут и одна попытка повтора
- Геокодирование областей — Nominatim, с тем же ограничением по нагрузке

### Google Places API (New) — точечное обогащение

Рейтинг, отзывы, часы работы. **Не** массовый обход: экономика этого не позволяет.

- С марта 2025 пулированный кредит $200 заменён по-SKU месячными лимитами:
  10 000 вызовов Essentials, 5 000 Pro, 1 000 Enterprise
- Text Search тарифицируется от уровня Pro (порядка $32 за 1000 вызовов), запрос полей
  рейтинга или часов поднимает вызов до Enterprise ($35–40 за 1000)
- Следствие для архитектуры: адаптер вызывается только по уже отобранным кандидатам,
  и каждый вызов проходит через бюджетный губернатор
- Требуется `PROSPEKTOR_GOOGLE_API_KEY`; без ключа адаптер не активируется

**Бюджетный губернатор.** Потолок задаётся `PROSPEKTOR_BUDGET_USD` и по умолчанию равен
нулю: случайный прогон не выставит счёт. Проверка идёт ДО вызова, поэтому перерасход
невозможен даже на один запрос — прогон отказывается работать, а не тратит.

### Сайты самих бизнесов

Источник почти всех сигналов групп B, C и D.

- `robots.txt` соблюдается. Мы аудируем чужой сайт, чтобы предложить владельцу
  улучшение; заходить туда, куда он просил не заходить, противоречит самой затее
- Пауза между запросами к одному хосту (`PROSPEKTOR_PER_HOST_DELAY`)
- Свой User-Agent с контактом — **замените значение по умолчанию**
- Обход ограничен: главная плюс по одной странице меню, контактов и заказа.
  Аудит не должен превращаться в обход всего сайта

### PageSpeed Insights

Метрики `seo.psi_*`. 25 000 запросов в день бесплатно, ключ в `PROSPEKTOR_PAGESPEED_API_KEY`.
Сервис капризен и часто отваливается по таймауту — отсутствие метрики не валит аудит.

## Tier 2 — «серые», спроектированы и выключены

Разбор публичных страниц `/maps/place/`, сторонние SERP и Maps API (Serper, Apify-акторы,
Scrap.io).

Положение дел, чтобы решение принималось с открытыми глазами: пункт «No Scraping» в
Google Maps Platform ToS это запрещает. При этом суды США с 2017 года последовательно не
видят в сборе публичных данных нарушения CFAA, и `/maps/place/` с `/maps/search/` открыты
в `google.com/robots.txt`. То есть риск здесь **договорный, а не уголовный**: блокировки,
отзыв ключей, cease-and-desist.

Механика включения: `PROSPEKTOR_ALLOW_GRAY=1` **и** `--legal-mode gray`. Факт использования
пишется в манифест прогона. Реализаций в `sources/gray/` пока нет намеренно: каркас готов,
решение включать — за человеком.

## Приоритет источников

При конфликте фактов побеждает источник с большим доверием (`SOURCE_TRUST` в
`src/prospektor/sources/__init__.py`), умноженным на собственную уверенность факта:

```
ceidg, krs, regon  0.95   реестр — первоисточник
google             0.85
osm                0.75   вносит человек, знающий это место
site               0.70   сам бизнес о себе
overture           0.60   агрегация, обновляется раз в месяц
gray               0.40
```

Проигравшие факты **не удаляются**: они остаются в таблице `facts`, и в досье видно,
кто что сказал и когда.

## Как добавить источник

1. Класс в `src/prospektor/sources/`, наследник `SourceAdapter`, с честными
   `legal_mode`, `cost_per_call` и `requires`.
2. Строка в `_CLEAN` (или в `GRAY_SOURCES`) реестра `sources/__init__.py`.
3. Вес в `SOURCE_TRUST`.
4. Фикстура — сохранённый ответ — и тест на разбор в `tests/test_sources.py`.
5. Строка в этой таблице: лицензия, лимиты, цена.

Пункт 5 не формальность. Источник, про который не написано, на каком основании он
используется, в прогон попадать не должен.
